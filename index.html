Slope through thickness

The 1:N ratio runs through the stock. Tail base and tail top are both computed, so you see if the slope eats the tail before you cut.

mm or inches

Work in whichever your gauges read. Millimeters to hundredths, inches to thousandths.

Fragility alarms

Too many tails, pins under 3mm, slopes that hollow the tail out - flagged while the board is still whole.

The layout rule

Through dovetails start and end with a half-pin so the joint has no weak end grain at the edges. Board width = two half-pins + every tail + every pin between them. Pick the pin size and tail count; the tails take what's left. Ratio 1:6 for softwood, 1:8 for hardwood is the usual guidance - both work here.

Checked by an independent implementation

The layout engine (engine.js) runs in Node against a second implementation in Python (tests/build_corpus.py). Both must agree on every half-pin, tail width, tail top and boundary mark across seven scenarios. 136 checks pass (node tests/run_tests.js).
